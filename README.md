# Socks5 Configurator (نسخه‌ی ساده‌شده)

اکستنشن کروم برای وصل کردن مرورگر به یک پراکسی Socks5 لوکال (مثلاً خروجی Nekoray) و بایپس کردن دامنه‌های دلخواه از پراکسی.

این پروژه فورکی از [socks5-configurator](https://github.com/txthinking/socks5-configurator) اصلیه که ساده‌ترش کردیم.

## قبلاً چطور بود

- برای روشن/خاموش کردن پراکسی یا اضافه کردن یک دامنه به لیست بایپس، باید یک **تب جدید** (صفحه‌ی تنظیمات) باز می‌شد، دستی دامنه تایپ می‌شد و دکمه‌ی Save زده می‌شد.
- فقط انگلیسی بود.
- تم روشن، بدون حالت دارک.

## الان چی شده

- یک **پاپ‌آپ سریع** اضافه شده: با کلیک روی آیکون افزونه، بدون باز شدن تب جدید می‌تونی پراکسی رو روشن/خاموش کنی یا سایتی که الان توش هستی رو با یک کلیک بایپس/آن‌بایپس کنی.
- **دارک‌مود خودکار**: هماهنگ با تم مرورگر/سیستم.
- **دو زبانه** شده (فارسی/انگلیسی)، با یک دکمه‌ی سوییچ ساده بالای صفحه.
- صفحه‌ی تنظیمات پیشرفته (برای ویرایش کامل لیست بایپس) هنوز هست، فقط ظاهرش نو شده.

## نصب (Load Unpacked)

1. برو به `chrome://extensions`
2. **Developer mode** رو روشن کن
3. **Load unpacked** رو بزن و همین پوشه رو انتخاب کن

# Socks5 Configurator (Simplified Version)

A Chrome extension to connect the browser to a local Socks5 proxy (e.g., Nekoray output) and bypass the proxy for specific domains.

This project is a simplified fork of [socks5-configurator](https://github.com/txthinking/socks5-configurator).

## Installation (Unpacked)

1. Go to `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked** and select this folder
